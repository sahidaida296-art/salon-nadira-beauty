# WEBSITE SALON NADIRA BEAUTY

## 1. Informasi Proyek
Nama Proyek: Website Salon Nadira Beauty
Nama Mitra: Salon Nadira Beauty
Jenis Proyek: Website Informasi dan Reservasi Salon

## 2. Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Visual Studio Code
- XAMPP

## 3. Fitur Website
- Halaman Beranda
- Halaman Tentang Kami
- Halaman Layanan dan Harga
- Halaman Galeri
- Halaman Kontak
- Formulir Reservasi
- Login Admin
- Pengelolaan Data Layanan
- Pengelolaan Data Reservasi
- Laporan Reservasi

## 4. Struktur Folder
- assets: Folder untuk kebutuhan aset website.
- config: Menyimpan konfigurasi dan koneksi database.
- css: Menyimpan file CSS dan JavaScript.
- databases: Menyimpan file SQL database.
- image: Menyimpan gambar salon.
- views: Menyimpan halaman website.

## 5. Cara Menjalankan Website
1. Instal dan buka XAMPP.
2. Aktifkan Apache dan MySQL.
3. Simpan folder proyek di dalam htdocs.
4. Buka phpMyAdmin melalui browser.
5. Buat database bernama salon_nadira.
6. Impor file salon_nadira.sql.
7. Pastikan pengaturan koneksi database sesuai.
8. Buka website melalui http://localhost/salon_nadira_beauty/
